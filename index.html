NexusFlow Engine

Deterministic matching. Paper books only.

Token-agnostic order-matching core: AVL price tree, FIFO levels, O(1) order-id cancel, single-writer sequencer, double-entry settlement. A future asset is another instrument row. This software is not legal authorization to operate a real-money exchange.

Runtime split

Matching actor belongs on a long-lived Node worker (Render). This Vercel surface is documentation only. Stateful book mutation is not hosted in a serverless isolate.
